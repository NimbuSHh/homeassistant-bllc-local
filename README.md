# BLLC Local — 布朗新风本地 Home Assistant 集成

通过设备现有 Wi-Fi 模块在局域网内控制布朗新风。不需要旧 App、机智云账号、云端令牌或 MQTT 服务。独立社区项目，与布朗、机智云没有官方关联。

## 支持范围

目前仅验证了两台 BE1.0 新风，Wi-Fi 硬件 `00MX3081`、固件 `04020015`、数据协议 `00000004`，产品定义为 `a2c216633edd4c6d9d2934aeb441508c`。同品牌或同系列不保证兼容；集成会拒绝不同产品定义和不同设备身份。

- 开关及低、中、高三档风速。
- 温度、湿度传感器。
- 每 15 秒轮询，持续本地连接；通信中断后有限重连。
- 控制后主动读取设备状态，确认后才更新 HA；不因回执丢失自动重发控制。
- 关机后开启恢复最近的手动档位，没有记录时使用中档。
- 不操作配网、绑定、滤芯复位、定时或含义未确认的模式 `4`。

风速在 HA 显示为 33%、66%、100%，关机为 0%。它们代表三档选择，不代表实测风量。推荐为设备保留固定 IP。

## 通过 HACS 安装

要求 Home Assistant 2026.10 或更新版本；当前测试版本为 2026.10.2。

1. 打开 HACS → 右上角菜单 → 自定义存储库。
2. 输入 `https://github.com/NimbuSHh/homeassistant-bllc-local`，类型选「集成」。
3. 找到 **BLLC Local**，下载最新发布版本，然后重启 Home Assistant。
4. 设置 → 设备与服务 → 添加集成 → 搜索 **BLLC Local**。
5. 填写新风的局域网 IPv4 地址和名称。设备本地凭证先留空，集成会尝试通过设备正常接口读取已有凭证。每台设备单独添加一次。

每台设备创建一个风扇和两个传感器。IP 变化时，在集成菜单选择「重新配置」。若设备不允许读取本地凭证，需要使用已取得的该设备本地凭证；集成不会重置或绕过认证。

也可手动将 `custom_components/bllc_local` 复制到 HA 配置目录中的 `custom_components/`，随后重启并按上述步骤添加。

## 本地通信与数据

运行期间只访问配置的局域网 IPv4 地址，使用 UDP `12414` 发现及 TCP `12416` 通信。HA 必须能访问设备所在网络。本地凭证保存在 HA 配置条目中，不上传到外部服务；不要公开包含凭证的 HA 配置或备份。

设备固件仍可能自行访问厂商服务器。本集成没有修改设备或路由器的联网权限，也未进行断外网测试。设备回读证明已接受模式，不能替代风量或机械运行测量。

## 移除

在「设备与服务」删除 BLLC Local 设备条目停止轮询，再从 HACS 移除集成并重启 HA。移除不会重置设备或改变绑定。原墙面面板可以继续使用。
